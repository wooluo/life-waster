# 人生虚度记录仪 ⏳

> **记录每一日虚度，看清余生还有多少时光。**
> 记录每一段时光，AI 光阴审计官评估虚度程度，理性复盘生命质量；健康数据自动导入。
> 备选名：时光审计局 / 余生倒计时 / 光阴质检员 · 定位：娱乐性时光复盘工具（效率/生活日志类目，纯本地隐私存储，完全合规）

「人生虚度记录仪」用你的出生日期搭起一座**余生倒计时**（首页常驻大号红色数字，逐秒跳动），再把每一段记录的时光交给 AI 光阴审计官「过审」：该扎刀的扎刀，该复盘的进 72 小时冷静期，该表彰的入高光时刻。健康数据（华为运动健康截图）拍照导入即自动回填档案，作为 AI 判定依据。

---

## 核心功能

| 功能 | 说明 |
|---|---|
| **生命档案** | 首次引导：出生日期 + 预期寿命 → 自动算出已度过天数、生命流逝占比、剩余天数/小时倒计时（AI 判定的寿命增减会动态刷新）；身高体重自动算 BMI，作息/病史/烟酒/运动随填随存 |
| **时光录入** | 文字日记（做了什么+耗时+感受）、拍照/截图（多模态识别）、语音录入感受（浏览器原生 Web Speech，零第三方 SDK）；四种素材一次递交 |
| **三档虚度评级** | 🟥 **重度虚度**（虚度指数≥70）：3~5 条扎心结论 + 替代方案，计入虚度台账／🟨 **中度浪费**（35~69）：自我拷问清单，进 72 小时冷静复盘／🟩 **高效充实**（<35）：判定有效光阴，自动存入「高光时刻」 |
| **虚度置信指数** | 0~100 虚度指数 + 置信指数双量化；每条结论带 1~5 ⚡扎心指数，逐条流式渲染 |
| **三档人格** | 📜 温和史官（平静理性娓娓道来）／👿 毒舌光阴质检员（阴阳幽默，只吐槽行为绝不攻击人格）／🕯️ 余生守望者（悲壮严肃「你又在消耗本就不多的余生」）。只换语气，不换判定逻辑 |
| **72 小时复盘冷静期** | 🟨 判定自动进复盘清单，72h 后首页弹窗回访「当初这件事，事后回头看，算不算虚度？」→ 二选一：确实虚度（计入虚度时长）/ 事后收获很大（修正为有效时光） |
| **虚度黑名单（翻旧账）** | 确认虚度的条目自动进黑名单；下次录入同类行为，AI 提示词自动附上「你曾在 X 月虚度过『刷短视频』2.5 小时，本次同类行为会拉高虚度评分」 |
| **华为运动健康导入** | 上传运动健康截图，GLM-5.3-flash 多模态自动识别睡眠时长/入睡起床/步数/运动时长/体重/心率，自动回填健康档案；图片只在本地留缩略图 |
| **月度光阴战报** | 按月聚合：虚度总时长/有效时长/光阴浪费率、虚度 TOP3、高光充实 TOP3、健康联动摘要、环比上月虚度率变化；一键复制分享文案 |
| **寿命趣味测算** | AI 对每段行为给出 life_change（折损/延养天数），首页倒计时动态调整并标注「仅供娱乐，不构成医疗结论」 |

**三档判定都会真实出现，不永远差评**——偶尔放松≠虚度，无节制重复刷手机才是。

## AI 输出与健壮性

- 严格 JSON 结构（`verdict` / `confidence` / `waste_index` / `reasons[]`(含 `sting_level`) / `questions?[]` / `alternatives?[]` / `life_change` / `save_time`），`waste_index` 与档位强制一致（≥70 waste / 35~69 normal / <35 valuable，指数存在时以阈值重新推导档位）。
- 合规红线写进提示词：**只做娱乐性时光评估，不做医疗诊断；寿命影响仅为趣味测算；不推荐任何保健品/药品/医疗方案；只吐槽行为，绝不羞辱人格。**
- 前端健壮解析：去 ```` ```json ```` 围栏、全角引号/尾逗号修复、档位同义词归一（重度虚度/高光时刻/待复盘…）、数值越界钳制；**失败降级 Markdown 原文展示 + 手动归档**。
- 流式输出支持**增量解析**：结论写完一条就渲染一条（`parse_partial`，Python/JS 双端同构）。
- 多模态：附截图走 OpenAI `image_url` / Anthropic `image` 内容块协议；默认 `glm-5.3-flash` 原生多模态（识图模型可在设置页按服务配置）。

## 架构（零第三方依赖）

与拔草机 / 六爻工程同构：

- **后端/网页**：Python 标准库（`http.server` + `urllib`），零 pip 依赖。`python3 app.py` 起 `http://127.0.0.1:8774`。`engine.py` 为纯逻辑引擎，`app.py` 负责网络与存储（`StreamHttpPlugin` 流式代理 → `open_upstream`/`iter_deltas`，`detectMode` 防误判，200-HTML 兜底）
- **前端**：原生 HTML+JS+CSS，无构建步骤。`static/engine.js`（核心引擎）与 `engine.py` 严格同构，保证网页版与 APK 离线版判定/统计行为一致
- **双运行模式**：
  - `server` 模式（连本机 Python 服务，服务端流式转发 + 数据存 `data/` 纯 JSON）
  - `client` 模式（APK / 直接双开 index.html）：数据在 localStorage，AI 请求**离线直连**厂商端点。安卓内置自研 `StreamHttpPlugin`（OkHttp SSE 原生流，绕过 WebView CORS）；`detectMode` 强制原生环境走 client，200-HTML 兜底不误判
- **安卓**：Capacitor 7 壳 + `mobile/build.sh` 一键出签名 APK；挖孔屏适配（`adjustMarginsForEdgeToEdge: force`）

## UI（时光审计账本风）

墨黑 + 深灰 + 暗金复古账本；判定卡片为旧纸审批单，盖红章【虚度不予通过】/ 黄章【待复盘】/ 金章【高光时刻】；确认虚度触发⏳沙漏漏光动画，高光时刻触发🪙光阴金币入账动画；首页余生倒计时大号红色数字逐秒跳动。

## 快速开始（网页版）

```bash
python3 app.py                # http://127.0.0.1:8774
python3 app.py --host 0.0.0.0 # 局域网内手机也可访问
```

首次打开会引导你建立生命档案（只存本机），然后在「档案」页配置 AI 服务（默认 GLM 智谱，填 API Key）即可开始记录。

## 安卓 APK

Releases 页下载 `人生虚度记录仪.apk` 直接安装。

本地构建（需 JDK 21 + Amazon Corretto / Android SDK，默认放在仓库外层同级 `tools/` 目录，或用环境变量指定）：

```bash
cd mobile && ./build.sh
# 产出 人生虚度记录仪.apk（正式签名版）与 虚度记录仪-debug.apk
# 工具链不在默认位置时：LW_TOOLS_DIR=/path/to/tools ./build.sh
```

正式签名需要 `mobile/keystore.properties`（连同 jks，均不入库；缺失时只出调试版）。

## 数据与隐私

出生日期、健康数据、台账等全部数据只保存在本机（网页版在 `data/`，App 在浏览器本地存储），不上传、不联网同步；健康截图只在本地保留缩略图；API Key 只存本机，AI 请求直连厂商端点，不经任何第三方。
